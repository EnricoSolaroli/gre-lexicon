# GRE Lexicon

Web app mobile per memorizzare il vocabolario GRE ad alta frequenza: 120 parole con pronuncia, definizione, sinonimi e contrari, frase in stile GRE e traduzione italiana.

- **Studia**: flashcard con ripetizione dilazionata ("Non la so", "Così così", "La so bene", oppure scorrendo).
- **Quiz**: Text Completion, Sentence Equivalence, definizioni.
- Progressi salvati sul dispositivo (localStorage), funziona anche offline.

**Installazione su iPhone**: apri il sito in Safari → Condividi → Aggiungi alla schermata Home.
